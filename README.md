# Bankole Olaoluwa — Portfolio

Employer-facing portfolio for **Bankole Olaoluwa**, positioned around business systems development, full-stack software engineering, digital operations, and systems thinking.

## Professional positioning

**Business Systems Developer**

I design and build software systems that help organizations simplify operations, connect workflows, and turn business problems into practical digital tools.

The portfolio is intentionally structured around the problems solved and systems built rather than a long list of technologies.

## Portfolio structure

## Tech

The live portfolio is a lightweight Vite-powered site using:

- HTML
- CSS
- JavaScript
- Vite

The site intentionally avoids unnecessary application complexity so the portfolio remains fast, portable, and straightforward to deploy.

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The generated site is written to `dist/`.

## Deployment

The project can be deployed to any static host that supports Vite builds.

Typical configuration:

- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `main`

## Portfolio principles

- **Employer-first clarity** — the first screen should make the professional value proposition obvious.
- **Problems before tools** — projects explain the operational problem and resulting system.
- **Evidence over claims** — live projects and repositories support the positioning.
- **Multidisciplinary by design** — prior experience in operations, media, and communication is presented as context for building better software systems.
- **Founder work supports the profile** — QORVEX and CORTEX demonstrate product-building work without replacing the individual professional identity.
